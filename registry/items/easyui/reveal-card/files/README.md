# Reveal Card

3D cursor physics tilt with interactive glare reveal

## Fonctionnalités

- Cursor-aware 3D perspective rotation springs
- Dynamic radial glare reflection overlay
- Hidden metadata section revealed on hover

## Props

| Prop | Type | Défaut | Description |
| --- | --- | --- | --- |
| `maxTilt` | `number` | `12` | Max tilt angle in degrees |
| `revealContent` | `ReactNode` | `undefined` | Content shown on hover |
